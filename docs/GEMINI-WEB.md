# Gemini web
## Bağlantı / veri yükleme
1. Bilgisayar tarayıcısında https://gemini.google.com adresinde doğru hesapla giriş yap.
2. Küçük görevde yalnız ilgili dosyaları veya ekran görüntüsünü ekle.
3. Repo gerektiğinde Add file > More Uploads > Import code yolundan repo/dal adresini içe aktar.
4. Özel repo için istendiğinde GitHub hesabını bağla. Kurumsal hesapta yönetici erişimi gerekebilir.
5. İçe aktarılan repo bir anlık kopyadır: sonraki GitHub değişiklikleri otomatik gelmez.
   Yeni incelemede doğru sürümü yeniden aktar veya değişen dosyaları ekle.
6. Bu bağlantı depoya yazmaz; önerileri Claude/Codex'e uygulat. Yalnız sohbet içine URL
   yapıştırmayı başarılı içe aktarma sayma. Reponun ek olarak göründüğünü kontrol et.

## Görev kalıbı
“Ekli [dosya/görsel] için yalnız [soru]yu değerlendir. Önemli en fazla 5 bulgu,
gerekçeleri ve uygulanabilir öneri ver. Görmediğin dosyalar hakkında varsayım yapma.
Kod değişikliği gerekiyorsa dosya adıyla öner; GitHub'a uyguladığını söyleme.”

## Verim
Her kod değişikliğinde ikinci kontrol isteme. Gemini'yi araştırma, referans karşılaştırması
ve görsel değerlendirme gereken görevlerde aç. Tüm eski sohbetleri ekleme.
Araştırma sonucunun özetini proje kararlarına aktar; aynı araştırmayı tekrarlama.
Başarılı bağlantı kanıtı: doğru depodan bir dosyanın gerçek içeriğini özetleyebilmesi.
Bu hesapta bağlantı ayrıca doğrulanmalı.

Kaynak: https://support.google.com/gemini/answer/16176929?hl=en
