# Çekirdek geri bildirimi
Oyun yapılırken çekirdekten (kural, görev paketi, dağılım, şablon, test, panel) kaynaklanan
gerçek eksikler. Ek AI turu açılmaz: işi yapan araç mevcut görevin sonunda tek satır ekler.
Oyun adı, mekaniği, hikâyesi veya verisi yazılmaz. Tahmin değil, görülen sorun yazılır.
Public depoda çekirdek toplayıcı "acik" satırları haftalık okur ve tek issue'da birleştirir.
tür: kural / paket / dagilim / sablon / test / panel. kanıt: ör. "ek tur: 2", "CI kaçırdı".
durum: acik / cekirdek#PR / red: neden. Aynı sorun tekrar görülürse kanıtı artır, yeni satır açma.
